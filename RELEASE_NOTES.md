# V16

COM3D2 Pregnancy provides pregnancy progression, adjustable belly and clothing deformation, and gradual body/color changes across pregnancies.

Extract the installation ZIP's `BepInEx` folder into the game directory with the game closed. Keep your customized preset pair when updating. Use F1 for settings and F8 for character state and shape controls.

See the [user guide](README.md), [changelog](CHANGELOG.md) and [build verification](VERIFICATION.md). The packaged plugin version remains **0.2.3**; use the **V16** release label to identify this build.
