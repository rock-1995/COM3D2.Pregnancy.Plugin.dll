# V15

- Adjustable upper/lower binding boundary arcs in F8.
- Improved body shading at breast and inner-thigh boundaries during deformation.

Extract the installation ZIP's `BepInEx` folder into the game directory with the game closed. Existing settings are retained; keep your customized preset pair when updating.

See the [user guide](README.md), [changelog](CHANGELOG.md) and [build verification](VERIFICATION.md). The packaged plugin version remains **0.2.3**; use the **V15** release label to identify this build.
